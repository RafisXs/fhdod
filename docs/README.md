# Documentação

O [README principal](../README.md) apresenta instalação, execução e comandos. Os caminhos técnicos abaixo são relativos à raiz do repositório.

| Pasta | Conteúdo |
| --- | --- |
| [guides/](guides/implantacao.md) | Implantação, configuração de produção, operação e recuperação. |
| [guides/entrada-em-producao.md](guides/entrada-em-producao.md) | Melhorias técnicas entregues, monitoramento e critérios de liberação institucional. |
| [deploy/](deploy/) | Modelos de Nginx, serviço systemd e backup MySQL. |
| [development/](development/estrutura.md) | Estrutura do projeto e responsabilidades das pastas. |
| [development/pendencias.md](development/pendencias.md) | Evoluções e definições institucionais ainda pendentes. |
| [reference/briefing-e-requisitos.md](reference/briefing-e-requisitos.md) | Problema, públicos, escopo e matriz de rastreabilidade do briefing. |
| [reference/decisoes-arquiteturais.md](reference/decisoes-arquiteturais.md) | Justificativa do MySQL, Node.js/Express e monólito modular. |
| [reference/plano-de-negocio.md](reference/plano-de-negocio.md) | Modelo de receita, custos, projeção, aquisição e escala. |
| [reference/oficializacao-parceria-fhdod.md](reference/oficializacao-parceria-fhdod.md) | Isenção, responsabilidades e checklist para formalizar a parceria. |
| [reference/manual-detalhado.md](reference/manual-detalhado.md) | Manual detalhado de funcionalidades, variáveis, API e indicadores. |
| [reports/](reports/README.md) | Relatórios datados de segurança, revisão e vistoria. |

Relatórios registram o estado observado em cada data. Capturas, bancos temporários, caches e backups locais pertencem a `verification/`, ignorado pelo Git, e não à documentação publicada.
